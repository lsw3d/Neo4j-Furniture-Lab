# Neo4j Furniture Lab

Учебный проект по работе с графовой базой данных **Neo4j** на Python.

Проект автоматически создаёт базу данных с сущностями покупателей, заказов, мебели, сборщиков и цехов, добавляет связи между ними и выполняет набор Cypher-запросов для получения и анализа данных.

## Структура проекта

```text
.
├── .env.example   # пример переменных окружения
├── lab.py         # основной файл запуска
└── queries.py     # Cypher-запросы
```

## Установка

### 1. Клонирование репозитория

```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd <ИМЯ_РЕПОЗИТОРИЯ>
```

### 2. Создание виртуального окружения

**Windows:**

```powershell
python -m venv .venv
.venv\Scripts\activate
```

**Linux/macOS:**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install neo4j prettytable python-dotenv
```

### 4. Настройка переменных окружения

Скопируйте `.env.example` в `.env`:

**Windows:**

```powershell
copy .env.example .env
```

**Linux/macOS:**

```bash
cp .env.example .env
```

При необходимости измените параметры подключения к Neo4j в `.env`.

### 5. Запуск

```bash
python lab.py
```

При первом запуске программа проверяет, пуста ли база данных. Если база пустая — создаются узлы и связи. Затем выполняются подготовленные Cypher-запросы и выводятся результаты.
